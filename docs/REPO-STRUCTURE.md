# Repository Structure

```
insurance-claim-manager/
│
├── README.md                        # Project overview, usage, numbers, author
│
├── insurance_manager.html           # The app — open this in any browser
│
└── docs/
    ├── HOW-IT-WAS-BUILT.md          # Full story — problem to working app
    ├── TECH-STACK.md                # Libraries, architecture, data structures
    ├── FULL-STACK-VERSION.md        # Node.js + SQLite + Claude API version
    ├── CLAUDE-CODE-PROMPT.md        # Prompt to build the full-stack version
    └── REPO-STRUCTURE.md            # This file
```

---

## Start Here

If you want to **use the app:** open `insurance_manager.html` in your browser.

If you want to **understand how it was built:** read `docs/HOW-IT-WAS-BUILT.md`.

If you want to **build the full-stack version with PDF upload:** copy the prompt from `docs/CLAUDE-CODE-PROMPT.md` into a Claude Code session.

If you want to **adapt this for your own claim:** read `docs/HOW-IT-WAS-BUILT.md` — the section "Replicating This for Your Own Claim" walks through it.
